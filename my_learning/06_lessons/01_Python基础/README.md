## 阶段开始：先看这里

**进入条件：** 不要求编程或机器学习基础。先能打开编辑器和终端即可；环境有问题跟P00操作，不先安装训练库。

**阶段目标：** 能独立运行文件，用变量、容器、循环、函数和对象表达一个简单程序。

从[本阶段第01章](01_P00_运行程序.md)开始，每次只开一章及它明确引用的材料。 一章可拆成多次45–60分钟，学不完就停在当前步骤，不按文件数量赶进度。

## 阶段结束：复盘与验收

**把章节串起来：** 闭卷写一个奖励累计函数：输入[1,0,2]返回3，空列表返回0；逐轮解释变量如何改变。再读随机agent，指出谁保存状态、谁选择动作。
