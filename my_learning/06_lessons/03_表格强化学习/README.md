## 阶段结束：复盘与验收

**把章节串起来：** 手画一个小环境，列出转移与奖励；算一次Bellman备份及一次Q更新；解释真实终止与时间截断的区别。

**要交付的证据：** 提交GridWorld实现、一次更新的手算与程序对照、独立评估结果；不以单次成功代替评估。

- [ ] 完成本阶段主线章节；选修区只检查你所选专题及其先修。
- [ ] 不翻答案完成上面的综合复盘，记录真实卡点。
- [ ] 执行 `python my_learning/coach.py report`，连同代码、输出和手算交给助手点评。
- [ ] 根据反馈修正一个错误，隔一天换例子再做一次。

**未通过怎么退：** 回报概念回R01，接口回R02，期望与最大化回R04，更新顺序回R05。Q表未弄懂不要急着换网络。
