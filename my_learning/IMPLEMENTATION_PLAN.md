# 零基础陪学路线：实施计划

## 需求与验收

对象：Python 薄弱、没有机器学习基础的中文学习者。目标：知道每次打开仓库做什么，能把视频直觉、公式手算、实际源码和练习连接起来；出错时知道退回哪一课，跨次学习能保留反馈。

验收：每课有先修、明确的视频选段/替代阅读、公式任务、具体实践、概念检查与解释、补救入口、提交证据；主线覆盖 Python 到 PPO/SAC，22 章均有去向；第一课只需要 Python 标准库；反馈工具能保存、恢复并解释进度，不能把选择题通过称为算法掌握。

## 已阅读的证据

- 根 README 与本地书籍目录：书籍以 Python 3.11 为基线；第 3 章迅速进入 PyTorch，第 6 章进入 Atari DQN。PDF 字体提取部分数字异常，教程以章节标题定位，不编造 PDF 页码。
- `Chapter02/01_agent_anatomy.py`：类、方法、循环就是最初门槛。
- `Chapter04/01_cartpole.py`：生成器、dataclass、batch 筛选、交叉熵优化同时出现。
- `Chapter05/01_frozenlake_v_iteration.py`：经验转移计数、概率加权和与最大化。
- `Chapter06/02_dqn_pong.py`：经验池、target、动作索引、终止处理。
- `Chapter11/02_cartpole_reinforce.py` 与 `Chapter16/03_train_ppo.py`：折扣回报、log probability、advantage、ratio/clip。
- 已有 `my_learning` 提供预备篇、22 章伴读、两个项目和练习工具；Python 预备篇直接进入 transition/类，环境第一课一次导入四个外部库，长期计划以会编程的人为基准。现有材料适合复用，但不足以充当逐次陪学入口。
- 当前默认 Python 3.13，NumPy、PyTorch、Jupyter 等未安装。新入口与反馈先用标准库；完整书籍训练需另建 3.11 环境，不自动安装庞大依赖。

这是重点主线抽样精读及目录核对，不是全仓库逐行审计，也不宣称已跑通重型训练。

## 实施顺序

1. 查证作者视频目录，记录核验日期、语言、具体选段与访问边界。
2. 增加小步课程：Python 拆成多课；数学从数字算例进入符号；之后逐章指向已有 notebook 和真实源码。专题明确先修与轻量替代。
3. 增加标准库反馈工具：逐题解释、补课定位、先修检查、本地持久化、实践证据与复盘报告。概念检查和实践自报分开。
4. 加入第一周逐步操作与公式示范；同步旧入口及生成器，避免重生成丢失新导航。
5. 检查课程依赖与路径、所有题目的合法性、反馈工具的成功/失败/中断/坏文件行为，执行新增轻量例子；运行现有 notebook 结构验证。缺少外部库时明确区分结构通过与实际训练未验证。

## 选择与边界

采用 Markdown 课卡 + 已有 notebook + 小型命令行反馈，复用现有材料。完整网页平台会引入新的运行门槛；只交付资源清单无法提供连续反馈，因此均不采用。学习节奏暂按每周 6–8 小时，按过关证据调节，不承诺固定日期学会。

保留上游 Chapter 源码、用户笔记和训练约束。自动反馈只判断明确答案；开放推导、代码质量和训练结果由学习者提交证据后与导师/助手复核。完成后的停止条件是教程、导航和反馈机制验证可用，不是替学习者完成学习。
