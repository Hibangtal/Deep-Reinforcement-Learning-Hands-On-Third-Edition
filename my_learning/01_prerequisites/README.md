# 01 · 零基础预备篇

从 [Prerequisite00 导航](Prerequisite00_Index.ipynb)开始，依次学习：

1. Python → NumPy → Matplotlib
2. 数学（线性代数与微积分）→ **4B 概率、采样与蒙特卡洛**
3. 机器学习基础 → **5B 神经网络从零开始**
4. PyTorch → **6B 卷积网络与序列模型**
5. Gymnasium → **7B 从多臂老虎机走进 RL**
6. [入学测试](Prerequisite08_Readiness_Check.ipynb)

带 **B** 的 4 个 notebook 是专为“没有机器学习基础”补的内容，原书默认读者已经会这些。
每个 notebook 末尾有**自动批改练习**：在练习格写代码并运行，看到 `[通过]` 才算完成；参考答案默认折叠。

已经有基础的人可以先做入学测试，错在哪里就补哪里。通过后进入[教材章节](../02_chapters/README.md)。
整体时间安排见[长期学习计划](../05_reference/LONG_TERM_PLAN.md)。
