# 从这里开始：有人带着走的强化学习路线

你现在不需要先啃完一本数学书，也不需要购买GPU。第一件事是运行几行Python，看懂结果，再一点点增加难度。

**这是唯一的日常学习入口。今天进入[阶段一 · Python基础](06_lessons/01_Python基础/README.md)，打开其中第01章。** 章节会带你做第一周的具体操作；完成后把实际输出和不懂的地方发给助手，下一次从记录继续。

只沿着 **本页 → 当前阶段目录 → 当前学习章节 → 章节中的下一步** 前进。视频、notebook和原书代码是章节按需引用的配套材料，不需要把所有md依次读一遍。

课号说明：**P = Prerequisites（前置基础），R = Reinforcement Learning（强化学习主线），O = Optional（选修专题）**。这些是保存进度的编号，不是原书章号；例如R03对应原书第4章。目录显示中文主题，无需先记住字母。

## 每次45–60分钟怎么用

1. 5分钟：闭卷回忆上一课，写一个还不清楚的问题。
2. 10–15分钟：按课卡只看指定视频段落。暂停，复述它解决的问题。
3. 10分钟：先把数字代入小例子，再看符号推导。
4. 15–20分钟：运行一小段，修改一个参数，比较预期与实际。
5. 5–10分钟：做检查题，记录代码/推导证据与错误。来不及就拆成两次，不跳过实践。

每周最后一次不学新课：复做一题、解释一个公式、整理一条错误。算法课允许分多次；视频看完不等于课已过关。

## 工具怎么给你反馈

所有命令都在**仓库根目录的终端**执行。前六课和反馈工具只用Python标准库，现有Python即可起步。

```bash
python my_learning/coach.py
python my_learning/coach.py lesson P00
python my_learning/coach.py quiz P00
```

第三条进入互动测验：输入选项数字，会立即得到解释。没有通过就按提示补课；通过后按P00课卡完成操作，再保存自己的真实证据，例如：

```bash
python my_learning/coach.py record P00 --evidence 'scratch/hello.py先输出5，改后输出6；解释器路径是我刚才打印的实际路径' --reflection '终端运行命令，文件里写Python；改完代码要重新运行'
python my_learning/coach.py status
```

请用自己的事实替换例子。工具不验证文件内容，实践记录属于**自报、待复核**。概念检查全对＋实践记录齐全，才解锁下一课的测验；仍可提前阅读任意课卡。先修复测失败会暂时阻止后续进阶，补好再继续。

进度保存在 `my_learning/progress.json`，只在本机，不自动发到任何服务。退出或关闭终端后仍在；中途取消一份测验不会覆盖之前进度。生成课卡不修改个人进度。不要把 `status` 中“已记录”理解为导师已认定掌握。

## 怎样让助手持续带你学

每次练习后执行：

```bash
python my_learning/coach.py report
```

把输出以及实际代码/手算过程交给助手。可以直接使用下面的约定：

> 我正在学习本仓库的P00（换成当前课号）。请先读对应课卡和我的反馈记录，一次只讲一个知识点，先问我一题再等我作答。不要立即给完整答案。指出我具体错在哪里，给第一层提示；仍不会再给一个小例子。通过后给一道换数字或换情景的题，再安排下一步。看视频、选择题、手算和独立代码能力要分别判断。

本轮提交四项即可：**当前课号、尝试的代码/推导、实际输出、最不确定的一句话**。报错时复制完整traceback，不只说“运行不了”。对于没有唯一答案的实验报告，助手/导师需要看证据后点评，命令行不会冒充智能批改。
